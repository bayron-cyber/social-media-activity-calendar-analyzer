# Activity Calendar Analyzer

Core modules:
- `io.py`: Load CSV
- `standardize.py`: Parse + standardize columns into a canonical schema
- `metrics.py`: Posting frequency, gaps, overloads, engagement rate
- `recommendations.py`: Recommend best posting times/formats/platforms
- `calendar_view.py`: Month calendar heatmap
- `dashboard.py`: Plotly HTML dashboard export
- `report.py`: Markdown report export
